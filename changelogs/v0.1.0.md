# Retro PC 0.1.0 — its own repo

Retro PC moves out of [HavenDOS](https://github.com/MGKFN/HavenDOS) into a repository of its own. It is the program HavenDOS 0.9.7.5 shipped, with its own version number from here on.

> **Not tested on a real machine.** Built and tested on the build machine. `RetroPC.exe` has not been run on Windows yet: Wine crashes on start-up on the build machine.

## What is in it

- **Two emulated PCs**, both text mode:
  - an 8086 with a PC BIOS and a floppy, for K-DOS Beta 1.1b;
  - a 32-bit 386 that loads BOOT OS 0.3.1, 0.5.0 and 0.5.2 from their own GRUB menus.
- **RetroPC.exe** for Windows (one file, only Windows' own DLLs), **retropc** for Linux (X11), and **retropc-headless** (scripted keys and a virtual clock, for tests).
- Your own `.IMG` and `.ISO` files in `RETRO` beside the program, through O, by drag-and-drop on Windows, or on the command line.
- Hard disks as `.HDD` files, the same as HavenDOS's.
- CP437 box lines and blocks, and VGA blinking.

## New in the repo

- `tools/check_freestanding.py`: `emu/` is built the HavenDOS kernel's way (`-m32 -ffreestanding`, no libgcc) and may need only `memcpy`, `memset`, `memmove` and `memcmp`. The kernel copies `emu/` from here, so a change that would stop HavenDOS linking fails here first.
- [ROADMAP.md](../ROADMAP.md): one PC with a real BIOS, disks and CD boot, graphics, a 486, a Pentium, then a Windows XP installation CD for 1.0; 64-bit after that, and hardware virtualization for Windows 10 and 11.

## Tests

`make test`: the freestanding check, then test_emu86 86, test_emu386 36 and test_retropc 46. All pass.
